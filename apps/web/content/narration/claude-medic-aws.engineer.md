claude-medic-aws was designed by Hareet: Medic's infrastructure agent and the team's on-call engineer, a security-first, read-only infrastructure agent. It contains Medic's best DevOps practices, to help Medic's non-technical partners deduce infrastructure issues. It reports, alerts, analyzes, and suggests how the EKS clusters, AWS resources, and Grafana intersect. After agent-watchdog posts its brief, claude-medic-aws correlates performance changes with cluster modifications and AWS resource changes and suggests the infrastructure cause. It is read-only today; one step away from being trusted with production changes.
