Hareet designed, architected, and built cht-agent, the multi-agent system in production for cht-core and cht-conf, and its data layer. He built the community that helped him build it, as per his design; it was mainly him building it. Its LangGraph research supervisor sits over a Documentation Access Layer and a Code Context Layer, with agent-memory (domains, workflows, knowledge base, indices), tickets as the unit of work, and human validation checkpoints. He designed its provider-agnostic routing through OpenRouter, and didn't build it. It runs the full loop on cht-conf issues and tickets, and it is being used on the datasource migration to Postgres.
