agent-watchdog was built by Hareet and released to production. It monitors all the CHT projects Medic knows of, updates the team and lets them interact with it, summarizes alerts for partners, and builds a knowledge base on correlated alerts and user feedback. It has secure, read-only access to non-sensitive metrics, and it flags and never acts.
