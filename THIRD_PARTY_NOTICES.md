## GitHub Spec Kit

The project's spec lifecycle (specify, clarify, plan, tasks, analyze, implement, converge) runs on [GitHub Spec Kit](https://github.com/github/spec-kit) 1.0.8, installed with its `specify` command on 2026-10-07 (`.specify/init-options.json`, `.specify/integrations/speckit.manifest.json`). These files are Spec Kit's, copied or generated by it, some since edited for this project:

- `.specify/**`: its templates, scripts, git extension, workflow, and settings. The exception is `.specify/memory/constitution.md`, this project's constitution, which is written from Spec Kit's template and is this project's own text.
- `.claude/skills/speckit-*/SKILL.md`: the skills its Claude integration and its git extension generate.

## Kokoro

The films' narration is a synthetic voice made with the Kokoro text-to-speech model (voice `af_heart`) through `kokoro-onnx` 0.6.1. The model is Apache-2.0 and `kokoro-onnx` is MIT, as `kokoro-onnx`'s package metadata states. Neither the model, its voices, nor the runtime is in this repository; only what they produced is: each film's `assets/voice.wav` and, for seven films, the word timings in `tools/voice-kokoro-raw.words.json`.
