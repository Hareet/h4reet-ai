## Format: `[ID] [P?] [Story?] Description (branch tag)`

- **[P]**: can run in parallel with the other [P] tasks of its group: different files, no dependency on an unfinished task.
- **[USn]**: the user story of a story phase. Setup, Foundational, and Polish tasks carry none.
- **"Author:"** opens a task only the Author does: in the Author's own terminal, on `main`, on the Author's devices, or on dev. Agents never do these steps.
- **The branch tag** ends each task: `(line R: <branch>)` or `(line I: <branch>)`, or the merge it is (`M1` to `M9`). "Waits for" names what must land first.
- **Patches.** A human-only path changes only by the Author's hand: `.claude/**`, `CLAUDE.md`, `REVIEW.md`, `.specify/memory/constitution.md`, `corpus/` (but `corpus/proposals/`), `tools/gates/**`, `evals/agent-config/**`, `assets/policy/**`, `config/prices.yaml`, `config/budgets.yaml`, and `config/alerts.yaml`. An agent task may write such a change as a `.patch` file beside its branch's note, checked in a scratch worktree; the Author's task applies it.
- **Heavy** marks an Author run that loads models or stops a service: no agent session uses the engine meanwhile.

## Path conventions

- The room's workspace is `apps/web/`: its data in `room/`, room text in `content/room/`, the compositor in `build/room/`, the shared kernel in `src/room/compose/`, the GLB reader in `src/room/glb/`, the 3D runtime in `src/room/scene/`, the renderers in `src/room/faces/`, the signals in `src/room/signals/`, the lookdev page in `lookdev/` and `src/lookdev/`, and the tests in `test/`.

- Studio files reach the repository only through the Author: `assets/room/**`, and a sign's outline under `apps/web/content/room/outlines/`.
- "§" means plan.md unless another file is named; R-nn is research.md's decision; Qn is quickstart.md's section.
