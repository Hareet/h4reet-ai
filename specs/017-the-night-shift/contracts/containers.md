# Contract: the container specs

Plan §1 and §2 hold the design; this file is what the tests check.

1. **Files**: `deploy/night-shift/containers/{supervisor,spec-writer,implementer,reviewer,red-teamer,ops,gate-runner,studio}.json`, plus the runner-only `plan.json` and `comfyui.json`. They are generated by `build.py` from `fragments.json`, and `build.py --check` exits non-zero when a committed file differs from what it would make.
2. **Shape** (JSON): `role`, `parent`, `image` (a name the install tags, never `latest`), `user` (`{{UID}}:{{GID}}`), `mounts` (each `{"host", "container", "mode": "ro"|"rw"}`), `networks`, `env` (names and values; `CLAUDE_CODE_OAUTH_TOKEN` comes only through `env_file`), `env_file`, `cap_drop: ["ALL"]`, `security_opt: ["no-new-privileges"]`, `read_only: true`, `tmpfs`, `limits` (`memory`, `cpus`, `pids`), `gpus` (studio and comfyui only), and `x-h4` (`example: true` in the repository).
3. **Never mounted, in any session spec**:
   - `$HOME/.aws`, `$HOME/.ssh`, `$HOME/.config/h4reet-ai`, `$HOME/.config/gh`, `$HOME/.git-credentials`, `$HOME/.docker`;
   - `$HOME/.claude` and `$HOME/.claude.json`;
   - `/srv/studio/photos` and `/srv/studio/key`;
   - `/var/run/docker.sock` and `/run/docker.sock`;
   - the main checkout's working tree;
   - and, but for the studio's, `/srv/studio/outputs`.

   Nor is any ancestor of these mounted (`$HOME`, `/`, `/srv`, `/srv/studio`, `/var/run`, `/run`).
4. **The masks**: every writing spec mounts these read-only over its read-write mounts:
   - `.git/hooks`, `.git/config`, `.git/info`, `.git/packed-refs`, and `.git/refs/heads/main`;
   - `.git/refs/tags`, since a tag named main would shadow the branch;
   - `.git/objects/info`, which holds the alternates;
   - the task's own `.git/worktrees/<task>/commondir`;
   - each path `GIT_NO_REPLACE_OBJECTS=1 git cat-file blob refs/heads/main:.claude/settings.json` lists in `sandbox.filesystem.denyWrite` that falls inside the worktree.

   The test reads main's settings the same way, so the masks follow main.
5. **Environment**:
   - no session spec names `ANTHROPIC_API_KEY`, `ANTHROPIC_AUTH_TOKEN`, `ANTHROPIC_BASE_URL`, `CLAUDE_CODE_USE_BEDROCK`, `CLAUDE_CODE_USE_VERTEX`, `CLAUDE_CODE_USE_FOUNDRY`, or any `AWS_` variable;
   - every session spec sets `HTTPS_PROXY=http://egress:3128` (the studio's: `egress-studio`), `SANDBOX_RUNTIME=1`, `DISABLE_AUTOUPDATER=1`, `DISABLE_TELEMETRY=1`, `DISABLE_ERROR_REPORTING=1`, and `CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC=1`.
6. **Managed settings and settings layers**:
   - every image carries `/etc/claude-code/managed-settings.json` with exactly `{"forceLoginMethod": "claudeai", "env": {"ANTHROPIC_API_KEY": "", "ANTHROPIC_AUTH_TOKEN": ""}}`, which the container probe's third run proved (research R-18);
   - the role layers (`deploy/night-shift/claude/<role>.settings.json`) set the role's permissions, and none sets `apiKeyHelper` or an `env` key for a credential.
7. **GPU containers** (studio, comfyui): `--read-only` off, because the NVIDIA runtime's hook writes into the container at start (the probe's third run). Every other lock (user, `cap_drop`, `no-new-privileges`, internal network, limits) stays.
7. **Networks**: every session spec's networks are internal. The `egress*` and `engine-fwd` containers are the only ones also on a normal network.
8. **Lattice** (plan §2): for each edge, the child's mounts (by host path and mode, `rw` covering `ro`), networks, devices, and capabilities are within the parent's. The runner's task mounts count as the role's. The ceiling is computed as the union, not a file.
9. **Placeholders**: `{{UID}}`, `{{GID}}`, `{{HOME}}`, `{{REPO}}`, `{{NIGHT_ROOT}}`, `{{COMFYUI_DIR}}`, `{{COMFYUI_VENV}}`, `{{COMFYUI_PORT}}`, `{{BLENDER_DIR}}`, `{{ENGINE_CERTS}}`. Any other `{{…}}` fails the build.
10. **Off**: no session spec mounts the plan's values, its saved plans, or the provider mirror; only `plan.json` does, and only the runner uses it.
11. **The example marker**: the runner refuses a spec file that has `x-h4.example`, or whose path isn't under `~/.config/h4reet-ai/night-shift/containers/`.
