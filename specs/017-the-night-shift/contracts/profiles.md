# Contract: the profiles

Plan §2 holds the table of grants and the lattice. This file is what the tests check.

1. **Files**: `deploy/night-shift/profiles/{supervisor,spec-writer,implementer,reviewer,red-teamer,ops,gate-runner,studio}.json`, generated by `build.py` from `fragments.json`. `build.py --check` exits non-zero when a committed file differs from what it would make.
2. **No `extends`** in any profile (research R-03).
3. **Denies in every profile**: `$HOME/.aws`, `$HOME/.ssh`, `$HOME/.config/h4reet-ai`, `$HOME/.config/gh`, `$HOME/.git-credentials`, `$HOME/.docker/config.json`, `$HOME/.claude`, `$HOME/.claude.json`, `/srv/studio/photos`, `/srv/studio/key`, `/srv/studio/outputs`.
4. **No grant** is an ancestor of a deny (nono refuses the overlap on Linux, R-03), and no grant is `$HOME`, `/`, `/srv`, `/srv/studio`, the main checkout's working tree, or its `.git` for writing.
5. **Never granted for writing**: `.git/hooks`, `.git/config`, `.git/info`, `.git/refs/heads/main`, `.git/packed-refs`.
6. **Lattice**: for each edge child → parent in plan §2, every filesystem grant of the child, by access, is covered by one of the parent's; every port of the child is the parent's; every command policy of the child is the parent's. The runner's task grants (contracts/runner.md §3) count as the role's.
7. **Ports**: as plan §2's table, and nothing else.
8. **Placeholders**: `{{REPO}}`, `{{NIGHT_ROOT}}`, `{{CLAUDE_BIN}}`, `{{BLENDER_BIN}}`, `{{BLENDER_DIR}}`, `{{COMFYUI_PORT}}`, `{{ENGINE_PORT}}`, `{{ROLE_CLAUDE_DIR}}`. Any other `{{…}}` fails the build.
9. **Off**: the plan and gate requests appear in no profile; they're the runner's (contracts/runner.md §5).
10. **The ceiling** isn't a file: the lattice test computes it as the union of the eight.
11. **Request profiles**: `deploy/night-shift/profiles/plan.json` and `gate.json`, outside the lattice, used only by the runner (FR-039). Their grants are listed in plan §3; a test checks that no session profile names them, and that neither grants a session's worktree for writing.
12. **The example marker**: `"x-h4": {"example": true, …}`. The runner refuses a profile file that has it, or whose path isn't under `~/.config/h4reet-ai/nono/`.
