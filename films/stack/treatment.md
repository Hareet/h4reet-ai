## The circuit (one world, 3200 × 1800, `#fworld` under `OM.camera`)

All fifteen prod services of `deploy/compose.yaml` (profile `gpu`) in their real topology:

- **THE HOST** (dashed wall) around everything but the two outside nodes; inside it, the **internal network** box (`internal: no route out`, compose.yaml:815-817), which every container joins.
- **EDGE** straddles the internal wall: the only node with a foot outside it, its six listeners as pills on **127.0.0.1** (x000 api, x001 Langfuse, x002 Grafana, x003 admin, x004 OTLP, x005 site; nginx.conf:4-9, compose.yaml:87-92). Requests start at the api and site pills.
- **WEB** below the edge (x005 → web).
- **GATEWAY** in the middle; its **egress** wire is the only one through both walls, up to **ANTHROPIC API** (the paid fallback, routing.yaml:73) and **TELEGRAM · EMAIL** (alerts.yaml:4), outside the host.
- **GATEWAY-STATE** below the gateway (the meter, the switch, the ledger, the audit log, the outbox).
- **MODEL-SERVER** right of the gateway (llama.cpp, on the GPU, serving Qwen3-30B-A3B-Instruct-2507 · Q4_K_M, deploy/models.lock:22).
- **OTEL COLLECTOR** below it, wired to **PROMETHEUS**, **LOKI**, and **LANGFUSE**'s group of six (langfuse-web, langfuse-worker, langfuse-db, clickhouse, valkey, seaweedfs).
- **GRAFANA** reading Prometheus, Loki, and gateway-state (its provisioned datasources); on the daily summary its lamp lights "CPU alert" (the Author's words, 2026-11-10).

Beads are functions of time (`OM.clock`); each request's route is decided by what is down when the bead reaches each node:

- white request beads from a 127.0.0.1 pill → edge → gateway → model server and back, green (local); every fourth one goes to the site → web and back;
- with the model server down: out through the egress to the Anthropic API and back, gold, plus a gold cost bead into gateway-state; with that down too, a crimson degraded bead back to the pill;
- with the edge down: requests die at the edge's wall; with web down: site requests bounce crimson at the edge (its own page); with the gateway down: api requests bounce crimson at the edge (`503 api_unavailable`); with gateway-state down: requests bounce crimson at the gateway (fail closed);
- small span beads gateway → collector after each answer, then metrics → Prometheus, logs → Loki, traces → langfuse-web (the collector down: nothing leaves it); Langfuse's members pulse as a trace moves through (web → valkey/seaweedfs → worker → clickhouse);
- tiny probe beads gateway → model server every `interval_ms` (1000), unanswered while it is down;
- green read beads Prometheus/Loki/gateway-state → Grafana, every 1.3 s;
- orange alert beads out through the egress to TELEGRAM · EMAIL: the outbox draining when the gateway is back, the store's one alert, the fallback's.

Each failure is a crimson flood on the node, from its word in the narration to the next group's cut.
