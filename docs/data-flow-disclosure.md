# Data-flow disclosure

Every flow of data that leaves the local tier, with what it carries and why (the constitution's Principle I; spec 000, FR-040). The local tier is the Author's own machine: the stacks run there in containers, on an internal Docker network with no route out, behind one proxy, `edge`, that publishes their ports on `127.0.0.1` only.

This is spec 000's disclosure, and it grows with the spec. Every service in `deploy/compose.yaml` has a row, whether or not it sends anything out: `make policy` (`tools/gates/compose_policy.py`) refuses a service whose name no row's **From** gives in backticks. So each task that adds a service, or a flow, adds its row in the same commit. The rows the plan lists that aren't here yet arrive with the tasks that create their flows (plan §17).

Columns: **From → To** names the sender and the destination. **Trigger** is what makes the flow happen. **Carries** and **Never carries** are its content. **Default** is whether it happens without anyone choosing it. **How to switch it off** is the operator's control.
