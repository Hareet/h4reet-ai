# Photo guide

Generated by `npm run room:generate -w apps/web` from its fixed template and `apps/web/room/scene.yaml`: don't edit it. Change the scene, or the template in `apps/web/build/room/orders.ts`, then generate it again.

Folders are named here by their role: the photos folder, the studio's inbox, and the workflows folder.

## Before the first shot

FR-026's steps:

1. Pause camera-roll backup and gallery sync until cleanup.
2. Turn location off.
3. Move the photos over a USB cable straight into the studio's photos folder.
4. Never send one through chat, email, a cloud drive, or an assistant.
5. Delete them from the phone and its trash once the studio's copy checks out.

## Where photo-derived files stay

FR-025:

> Every file a photo touches SHALL stay inside the photos folder, which, with the blinding key, every Claude session on the machine is denied, the studio's own included: ComfyUI's input, output, temp, and user folders (its `--input-directory`, `--output-directory`, `--temp-directory`, and `--user-directory`), and any Blender file that loads or links a photo, with its temporary files and autosaves. The studio's own Blender files, temporary files, and autosaves SHALL sit in the workflows folder. Only what FR-024 lets the studio's agent receive from a photo, each after the Author has reviewed it (a style frame, a mesh stripped to geometry, or a sign's lettering outlines; FR-032), SHALL leave the photos folder, into the studio's inbox.

## Setting up photo work

Before each session that opens a photo or a file made from one (FR-025's side files and listeners, FR-026):

- **Blender's Temporary Files.** Start Blender for photo work with a Blender configuration of its own, kept inside the photos folder, whose Temporary Files folder is a folder inside the photos folder, so its autosaves, `quit.blend`, and recent-files list stay there. The studio's own Blender keeps its own configuration, with its temporary files in the workflows folder.
- **TMPDIR.** Start every photo-work tool from a shell whose TMPDIR is that folder inside the photos folder, never the system temp folder, which this repository's sandboxed sessions can read.
- **The tracing tool's autosave.** Off.
- **The tracing tool's recent files.** Off, so no list of opened files sits outside the photos folder.
- **ComfyUI.** Started with its four folders inside the photos folder, listening on 127.0.0.1 alone, its default; the Author queues its workflows, and no Claude session reaches its port (Confirmation 24).

## The photo-work checklist

- [ ] TMPDIR is inside the photos folder.

- [ ] The tracing tool's recent files are off.
- [ ] ComfyUI listens on 127.0.0.1 alone, and only the Author queues it.

## Tracing a sign's lettering

With every line of the photo-work checklist ticked (FR-032):

1. Trace the lettering with a local tool that runs offline inside the photos folder.
2. Convert its paths to the outline file of contracts/room-data-files.md §8.
3. Run P-8's `outline_check.py` on it there.
4. Review the outlines.
5. Move only the outline file to the studio's inbox.
