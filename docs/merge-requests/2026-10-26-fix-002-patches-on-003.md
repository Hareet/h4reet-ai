### The script's guards (T047)

- **Pins.** `MERGES` gives, for each file, the SHA-256 of its bytes as git leaves them after the note's merge from a964494 (`-c merge.conflictStyle=merge`, so a `diff3` or `zdiff3` setting in your config can't change the shape), and its conflict count. The script reads bytes, so CRLF line ends change the hash too. Any other file refuses, before any rule runs, with "main or the merge differs from the note's; git merge --abort, and tell the agents".
- **`|||||||` refuses on its own,** before the pin, with a message naming the conflict style.
- **The rules' own checks stay,** for a reader: CHECK_GATES's two sides equal a964494's and the branch's lines; the help line and the table row each rule drops equal a964494's; each Makefile hunk the web rule rewrites holds `gateway-image compose-images` once; START-HERE's two clauses are where they were.
- **Paths:** the current directory must hold `.git`, and each file must be a regular file at its own path below it, with no link on the way (`Path.resolve()` must equal the joined path).
- **Standard input:** it reads nothing of its own and names no path of its own, so `cat-file blob … | python3 -I - <rule>` runs it. `-I` keeps the current directory off `sys.path`.
