### Departures from the plan, recorded in the same commit
- **A round's result is a file**: `line.py candidate --record` writes `<briefs>/<asset>/<round>.result.json` once, for the round's own handoff folder only. The next brief must follow a recorded failure and carry its findings verbatim. Since repo agents can write the briefs folder, `line.py round` counts the rounds used from the studio's handoff folders too, and re-checks a recorded pass (review, blocker 2).
- **`line.py round` prints five states**: `1`, `open N`, the next round's number, `passed N`, `decide`. The contract said "the next round, or `decide`".
- **The intended `assets/` path is the record's `directory`**, which the arrival check already requires to be the folder it's in; not under `assets/policy/`.
- **Every command takes `--repo`** (default: the working directory) for the repository whose `refs/heads/main` gives the policy and the arrival check, and **`--handoff`** (default `/srv/studio/handoff`). There's no `--caps` or `--tools`: the contract had them as paths (review, blocker 1).
- **The ComfyUI test lives in `scripts/studio/`**: `deploy/night-shift/tests/` isn't in the Makefile's `PYTEST_DIRS`, and G3 doesn't edit the Makefile.
